# ADR 0001 — 검사 엔진은 후보만 돌려준다

- 상태: 채택 (2026-11-19)

## 배경

검사 대상(김치 이물 / 트레이 누락)이 아직 정해지지 않았다. 엔진이 정해질 때까지 파이프라인을 멈출 수 없다.

## 결정

- 엔진 인터페이스는 `detect(image) -> list[DefectCandidate]` 하나뿐이다.
- OK/NG/REVIEW 판정, DB 저장, Lot 처리는 엔진 밖(`routing.py`, `services/`)에서 한다.
- 판정 기준값은 코드가 아니라 `ModelVersion` 행에 저장한다.
- 개발 초기에는 `MockEngine`(시드 고정, 재현 가능)으로 전체 흐름을 만든다.

## 결과

- 엔진을 바꿔도 검수·조치 흐름과 테스트는 그대로다.
- 버전별 기준값이 DB에 남아서, 판정 결과를 버전 간 같은 기준으로 비교할 수 있다.
- 대신 엔진별 특수 정보(예: 세그멘테이션 마스크)는 지금 구조로 담기 어렵다. 필요해지면 `DefectCandidate`에 선택 필드를 추가한다.

## 검토한 대안

- **엔진이 판정까지 반환**: 엔진마다 판정 규칙이 달라져 비교가 불가능해진다.
- **기준값을 설정 파일에 저장**: 과거 검사가 어떤 기준으로 판정됐는지 추적이 끊긴다.
